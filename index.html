Qameti System

Run a savings committee (qameti / ROSCA) without paperwork. Name the creator at the start — the creator is locked to Number 1 and always receives the first month's payout. Add the other members, let the system draw the remaining numbers and allot each member a payout month automatically, record the monthly entries, and get a clean report for every month.

1 Create a Qameti

Committee setup

One qameti = one full cycle. If you add 10 members, the cycle runs for 10 months and every member receives the full pool once. As per the usual rule in Pakistan, the first qameti always goes to the creator — so the creator is locked to Number 1 and the first month.

The creator is added as the first member and locked to No. 1 — first month's payout.

    Draw numbers & allot months
